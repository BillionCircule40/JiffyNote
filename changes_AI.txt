### Phase 5: Docker & Database Setup

**Priority:** High
**Estimated Time:** 6-8 hours

#### Tasks:
1. **Docker Configuration**
   - [ ] Create Dockerfile for application
   - [ ] Create docker-compose.yml for PostgreSQL
   - [ ] Configure environment variables
   - [ ] Set up network configuration

2. **Database Schema Design**
   - [ ] **Users Table:**
     - id (UUID, primary key)
     - username (VARCHAR, unique)
     - email (VARCHAR, unique)
     - password_hash (VARCHAR)
     - created_at (TIMESTAMP)
     - updated_at (TIMESTAMP)
   
   - [ ] **Calendar Events Table:**
     - id (UUID, primary key)
     - user_id (UUID, foreign key)
     - title (VARCHAR)
     - description (TEXT)
     - start_time (TIMESTAMP)
     - end_time (TIMESTAMP)
     - color (VARCHAR)
     - created_at (TIMESTAMP)
     - updated_at (TIMESTAMP)
   
   - [ ] **Notes Table:**
     - id (UUID, primary key)
     - user_id (UUID, foreign key)
     - title (VARCHAR)
     - content (TEXT)
     - created_at (TIMESTAMP)
     - updated_at (TIMESTAMP)
     - is_reminder (BOOLEAN)
     - reminder_type (VARCHAR: 'now', 'later', 'todo')
   
   - [ ] **Event-Note Attachments Table:**
     - id (UUID, primary key)
     - event_id (UUID, foreign key)
     - note_id (UUID, foreign key)
     - created_at (TIMESTAMP)

3. **Database Migration Scripts**
   - [ ] Create initial schema migration
   - [ ] Add seed data for testing
   - [ ] Create indexes for performance
   - [ ] Add constraints and relationships

4. **Application Database Integration**
   - [ ] Replace localStorage with database queries
   - [ ] Implement user authentication
   - [ ] Add data synchronization logic
   - [ ] Handle offline scenarios

**Files to Create:**
- `Dockerfile` - Application container
- `docker-compose.yml` - Multi-container setup
- `database/migrations/` - Migration scripts
- `database/seed/` - Seed data scripts
- `src/services/databaseService.ts` - DB connection management
- `src/services/authService.ts` - Authentication logic

**Files to Modify:**
- `src/DataBase/DataBaseQueries.ts` - Complete implementation
- `src/App.tsx` - Add authentication checks
